# Mobile Chi (WoodMart) — موبایل چی

پوسته فرزند وردپرس برای بازتولید ظاهر دمو **«موبایل چی»**:
https://demo-serverha.ir/woodmart/mobile-chi/

این پوسته با بررسی کد منبع صفحه دمو ساخته شده و مقادیر کلیدی آن را استخراج کرده است:

| مورد | مقدار در دمو |
|---|---|
| قالب والد | WoodMart (`Template: woodmart`) |
| رنگ اصلی `--wd-primary-color` | `rgb(67,95,203)` → `#435fcb` (روشن‌تر: `#3965ef`) |
| جهت صفحه | RTL، زبان `fa-IR` |
| فونت | `yekanbakh` / `IRANSans` (با fallback به Tahoma/Arial) |
| گرید محصولات | ۴ ستونه (`product-grid`) |
| هدر | نوار بالا + هدر اصلی چسبان (`whb-top-bar`, `whb-main-header`) |
| پاپ‌آئیک Quick View | `--wd-popup-width: 920px` |

## ساختار

```
mobile-chi/
├── style.css                     # هدر شناسایی پوسته + متغیرها و رنگ‌های اصلی
├── functions.php                 # بارگذاری استایل/اسکریپت، منوها، ویجت، ووکامرس
├── page-mobile-chi-home.php        # قالب برگه «Mobile Chi Home» (اسلایدر + دسته‌بندی + محصولات جدید)
├── assets/
│   ├── css/mobile-chi-rtl.css      # استایل راست‌به‌چپ (حالت پیش‌فرض فارسی)
│   ├── css/mobile-chi-ltr.css      # استایل چپ‌به‌راست (fallback)
│   └── js/mobile-chi.js            # رفتار هدر چسبان شبیه دمو
└── languages/                    # فایل‌های ترجمه (اختیاری)
```

## نصب

1. قالب **WoodMart** (والد) و افزونه **WooCommerce** باید نصب و فعال باشند.
2. پوشه `mobile-chi` را در `wp-content/themes/` آپلود کنید.
3. از پیشخوان > نمایش > پوسته‌ها، پوسته «Mobile Chi (WoodMart) — موبایل چی» را فعال کنید.
4. برای صفحه اصلی، برگه‌ای بسازید و قالب **Mobile Chi Home** را به آن اختصاص دهید؛ سپس آن را به‌عنوان صفحه اصلی تنظیم کنید (تنظیمات > خواندن).
5. رنگ اصلی را می‌توانید در WoodMart > تنظیمات پوسته > رنگ‌ها روی `#435fcb` تنظیم کنید تا با `--wd-primary-color` دمو یکسان شود.

## نکات

- این پوسته یک **Child Theme رسمی** برای WoodMart است؛ بنابراین آپدیت قالب والد تنظیمات شما را از بین نمی‌برد.
- اسلایدر و بنرها از طریق ویجت‌های WoodMart در ناحیه «منطقه اسلایدر خانه موبایل چی» قابل افزودن هستند.
- نام‌ها و تصاویر محصول دمو شامل نشده‌اند؛ فقط ساختار، رنگ‌بندی، فونت و چیدمان بازتولید شده است.
## افزوده‌های نسخه ۱.۱

- **ویجت‌های المنتور** (`inc/mobile-chi-elementor-widgets.php`): سه ویجت «اسلایدر موبایل چی»، «دسته‌بندی محصولات» و «محصولات» (جدیدترین/تخفیف‌دار/پرفروش) در دسته اختصاصی *موبایل چی*.
- **ردیف نمادهای اعتماد فوتر** (`inc/mobile-chi-footer.php`): سایدبار `mobile-chi-trust-badges` + هوک `woodmart_before_footer`.
- **Customizer**: بخش «تنظیمات موبایل چی» با انتخاب رنگ اصلی (پیش‌فرض `#435fcb`) و کلید نمایش ارقام فارسی قیمت‌ها.
- **جاوااسکریپت**: هدر چسبان با placeholder (بدون پرش صفحه)، دکمه «بالا رفتن» و دریافت تنظیمات از `wp_localize_script` (object `MobileChi`).
- **زبان**: فایل‌های `languages/mobile-chi.pot`، `mobile-chi-fa_IR.po/.mo`.
