# Tikakala Child Theme (WoodMart)

پوسته فرزند وردپرس برای بازتولید ظاهر دمو **«تیکا کالا»**:
https://demo-serverha.ir/woodmart/tikakala/

این پوسته با بررسی کد منبع صفحه دمو ساخته شده و مقادیر کلیدی آن را استخراج کرده است:

| مورد | مقدار در دمو |
|---|---|
| قالب والد | WoodMart (`Template: woodmart`) |
| رنگ اصلی `--wd-primary-color` | `rgb(67,95,203)` → `#435fcb` (روشن‌تر: `#3965ef`) |
| جهت صفحه | RTL، زبان `fa-IR` |
| فونت | `yekanbakh` / `IRANSans` (با fallback به Tahoma/Arial) |
| گرید محصولات | ۴ ستونه (`product-grid`) |
| هدر | نوار بالا + هدر اصلی چسبان (`whb-top-bar`, `whb-main-header`) |
| پاپ‌آئیک Quick View | `--wd-popup-width: 920px` |

## ساختار

```
tikakala-child/
├── style.css                     # هدر شناسایی پوسته + متغیرها و رنگ‌های اصلی
├── functions.php                 # بارگذاری استایل/اسکریپت، منوها، ویجت، ووکامرس
├── page-tikakala-home.php        # قالب برگه «Tikakala Home» (اسلایدر + دسته‌بندی + محصولات جدید)
├── assets/
│   ├── css/tikakala-rtl.css      # استایل راست‌به‌چپ (حالت پیش‌فرض فارسی)
│   ├── css/tikakala-ltr.css      # استایل چپ‌به‌راست (fallback)
│   └── js/tikakala.js            # رفتار هدر چسبان شبیه دمو
└── languages/                    # فایل‌های ترجمه (اختیاری)
```

## نصب

1. قالب **WoodMart** (والد) و افزونه **WooCommerce** باید نصب و فعال باشند.
2. پوشه `tikakala-child` را در `wp-content/themes/` آپلود کنید.
3. از پیشخوان > نمایش > پوسته‌ها، پوسته «Tikakala Child (WoodMart)» را فعال کنید.
4. برای صفحه اصلی، برگه‌ای بسازید و قالب **Tikakala Home** را به آن اختصاص دهید؛ سپس آن را به‌عنوان صفحه اصلی تنظیم کنید (تنظیمات > خواندن).
5. رنگ اصلی را می‌توانید در WoodMart > تنظیمات پوسته > رنگ‌ها روی `#435fcb` تنظیم کنید تا با `--wd-primary-color` دمو یکسان شود.

## نکات

- این پوسته یک **Child Theme رسمی** برای WoodMart است؛ بنابراین آپدیت قالب والد تنظیمات شما را از بین نمی‌برد.
- اسلایدر و بنرها از طریق ویجت‌های WoodMart در ناحیه «منطقه اسلایدر خانه تیکا کالا» قابل افزودن هستند.
- نام‌ها و تصاویر محصول دمو شامل نشده‌اند؛ فقط ساختار، رنگ‌بندی، فونت و چیدمان بازتولید شده است.
